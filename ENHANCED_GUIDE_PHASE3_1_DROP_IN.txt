SLIMEFUN LEGACY ENHANCED GUIDE PHASE 3.1 — DROP-IN INSTRUCTIONS
================================================================

Use this incremental package only after Enhanced Guide Phase 3 is already installed.

1. Back up the Slimefun Legacy source repository.
2. Extract the Phase 3.1 incremental ZIP into the repository root.
3. Preserve all folder paths and replace matching files.
4. Commit the files.
5. Run the normal GitHub Actions build.
6. Install the newly built Slimefun JAR and fully restart the server.
7. Keep the existing FastMachines JAR. No FastMachines source rebuild is required.

Expected player result:
- Open a FastMachines machine in the enhanced guide.
- A Machine Recipes knowledge-book button appears in the lower-right area.
- Click it to browse all enabled recipes that machine can process.

Configuration:
plugins/Slimefun/enhanced-guide.yml

features:
  machine-recipes:
    enabled: true
