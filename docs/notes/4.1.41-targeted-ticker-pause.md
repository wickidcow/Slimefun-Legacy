# Slimefun Legacy 4.1.41 — Targeted Ticker Pause

This slice adds diagnostic ticker pauses without changing ticker registration, machine storage, or addon callbacks.

## Commands

- `/sf tick freeze at` pauses the single ticking machine being looked at.
- `/sf tick unfreeze at` resumes that location.
- `/sf tick freeze <item-id>` pauses every ticking machine registered under that Slimefun item id.
- `/sf tick unfreeze <item-id>` resumes that item type.
- `/sf tick frozen` reports global, location-targeted, item-targeted, and circuit-breaker pause counts.

## Runtime behavior

Targeted pauses are in-memory diagnostic state only. They do not unregister tickers, mutate block data, move callbacks to another executor, or persist across plugin shutdown. Already-dispatched work may finish; future callbacks are skipped at the existing ticker dispatch boundary.

On Folia the targeted pause check is repeated after entering the ticker's region-owned/serialized callback section, so a pause issued while work is being queued cannot accidentally permit a later callback to run.
