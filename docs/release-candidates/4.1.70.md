# Slimefun Legacy 4.1.70 release readiness

## Decision and frozen scope

Prepare one coordinated Slimefun Legacy **4.1.70** release with the **45 maintained addons** in canonical source-matrix revision **125**. Baseline preparation starts at merged master `3af38ae8e27c8caba9218b93d9b07c00aaa5456d`. Accept release-blocking fixes only; do not keep advancing addon versions merely because another maintenance opportunity is found.

The version-preparation branch does not authorize a stable publication or a live-server update. Keep all item/research IDs, persistent formats, inventories, recipes, machine rates, energy costs, migration defaults and owner configuration unchanged. A genuine blocker needs a scoped regression test and fresh validation; never hide it by suppressing a check or replacing a failed exact-source artifact with an older green one.

`SF_BetterStructuresLink` is not in the 45-addon canonical matrix. Its documented artifact is `SF_BetterStructuresLink-0.3.1-SNAPSHOT.jar` and it requires BetterStructures. Its prior 0.3.0 startup problem was corrected by building against the genuine Paper API. Before calling this optional bridge stable, verify its current exact source/build, numeric release identity, Paper-floor and primary-target checks, real BetterStructures event integration, provider-absent behavior and loot limits. Do not add a snapshot or its external dependency to the frozen main bundle without a separately reviewed source-matrix change and full-stack validation.

The resource-pack ID preview is not promoted by this release. Rebar/Pylon development and unrelated server plugins stay outside this release workstream.

## Meaning of ready

A ready release has a fixed, inspectable source set, passing relevant regression and integration gates, matching shipped artifacts, preserved data/configuration, clear dependency instructions and explicitly documented testing limits. It is not a promise of perfection, complete Folia support for every addon, or arbitrary old-world/cross-fork rollback safety.
