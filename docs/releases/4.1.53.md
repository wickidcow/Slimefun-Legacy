# Slimefun Legacy 4.1.53 — Resource-Pack Addon Config & Release Cleanup

Slimefun Legacy 4.1.53 is a small follow-up patch on top of 4.1.52. It keeps the 4.1.52 storage, addon, and compatibility fixes intact while moving the optional Slimefun Legacy resource-pack sender into the dedicated Legacy addons configuration file.

## Included from 4.1.52

4.1.53 includes all 4.1.52 fixes, including:

- the Paper/Purpur empty ItemStack serialization race fix
- delayed inventory ItemStack snapshotting before persistence
- the corrected canonical addon bundle with InfinityExpansion2/DynaTech MobDataCard conflict handling
- the official optional resource-pack URL:
  `https://github.com/wickidcow/SFL_RP_Official/releases/latest/download/SlimefunLegacyRP.zip`
- current Paper 1.21.11, 26.2, and 26.3 compatibility work

## Resource-pack settings now live in configSFLAddons.yml

The optional Legacy resource-pack sender is now configured in:

`plugins/Slimefun/configSFLAddons.yml`

instead of the generic Slimefun `config.yml`.

The configuration remains disabled by default and is independent of the top-level Curiosities/additions `enabled` switch.

Server owners can set their own direct HTTP(S) resource-pack ZIP:

```yaml
resource-pack:
  enabled: false
  url: 'https://github.com/wickidcow/SFL_RP_Official/releases/latest/download/SlimefunLegacyRP.zip'
  sha1: ''
  required: false
  prompt: 'Slimefun Legacy resource pack'
```

A custom `resource-pack.url` is preserved; the GitHub-hosted Slimefun Legacy pack is only the default.

## Automatic migration

Existing servers that already have a `resource-pack:` section in `plugins/Slimefun/config.yml` are migrated automatically.

Migration:

- copies existing values into `configSFLAddons.yml`
- does not overwrite values already configured in the addon config
- removes the retired core-config section only after the addon config saves successfully
- adds any missing resource-pack defaults to older `configSFLAddons.yml` files

## Compatibility and validation

The 4.1.53 candidate retains the 4.1.52 release as its previous-stable regression baseline.

Release validation covers:

- Paper and Purpur 1.21.11
- Paper 26.2
- Purpur/Folia/Leaf 26.2
- Paper 26.3 pre-release compatibility
- full-stack addon smoke
- required-addon runtime smoke
- public API compatibility
- gameplay correctness

The canonical addon bundle remains `SF_Addons_1.21.11-26.3.zip` at bundle revision 25; this patch changes Slimefun Legacy configuration behavior, not addon contents.
