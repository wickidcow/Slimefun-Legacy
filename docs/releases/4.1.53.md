# Slimefun Legacy 4.1.53 — Config Compatibility & Resource-Pack Cleanup

Slimefun Legacy 4.1.53 is a focused compatibility patch on top of 4.1.52. It keeps the storage, backpack, addon, and Paper/Purpur fixes from 4.1.52 while cleaning up where Legacy-only resource-pack settings are stored.

## Keep the normal Slimefun config portable

The optional resource-pack controls no longer live in the normal:

`plugins/Slimefun/config.yml`

They now live in the dedicated Slimefun Legacy additions file:

`plugins/Slimefun/configSFLAddons.yml`

This keeps the standard Slimefun configuration cleaner and easier to reuse when moving between compatible Slimefun variants.

The resource-pack controls are independent from the built-in addon master toggle.

## Resource-pack settings

The dedicated configuration now contains:

```yaml
resource-pack:
  enabled: false
  url: 'https://github.com/wickidcow/SFL_RP_Official/releases/latest/download/SlimefunLegacyRP.zip'
  sha1: ''
  required: false
  prompt: 'Slimefun Legacy resource pack'
```

The GitHub-hosted Slimefun Legacy pack remains the default, but server owners may replace `resource-pack.url` with any direct HTTP(S) resource-pack ZIP URL.

Resource-pack delivery remains disabled by default.

## Automatic migration from 4.1.52

Servers that already ran 4.1.52 may have a `resource-pack:` section in the normal `config.yml`.

4.1.53 automatically:

1. reads those existing values,
2. writes them into `configSFLAddons.yml`,
3. verifies the dedicated config saved successfully,
4. removes the old `resource-pack:` section from `config.yml`.

A custom owner-supplied URL, SHA-1, prompt, enabled state, and required state are preserved during migration.

If the dedicated file cannot be saved, Legacy leaves the old settings in `config.yml` instead of deleting them.

## Regression protection

CI now verifies that:

- the normal bundled `config.yml` does not contain a `resource-pack:` tree,
- `configSFLAddons.yml` does contain the resource-pack controls,
- the official default pack URL remains present,
- custom HTTP(S) resource-pack URLs are preserved instead of being replaced.

## Included 4.1.52 fixes

4.1.53 includes all core work already shipped in 4.1.52, including:

- the Paper/Purpur `Empty itemstack cannot be serialized` delayed-storage race fix,
- cloned delayed inventory snapshots and native `ItemStack.isEmpty()` handling,
- backpack persistence/session hardening,
- the official Slimefun Legacy resource-pack URL,
- Magic 8 Ball integration,
- the canonical addon bundle with the InfinityExpansion2/DynaTech duplicate MobDataCard registration fix,
- Paper/Purpur 1.21.11 and Paper-family 26.2 compatibility coverage,
- Paper 26.3 compatibility validation.

The canonical addon bundle remains revision 25 because no addon code changed in this patch.
