# Slimefun Legacy 4.1.62

Slimefun Legacy 4.1.62 promotes **Paper/Minecraft 26.3** to the primary API/support line while retaining the established **Paper/Purpur 1.21.11+** compatibility floor and Java 21 Slimefun bytecode target.

## Paper 26.3 primary support

- Paper API `26.3.build.+` is now the default production compile target.
- The build toolchain remains Java 25 while Slimefun-owned classes continue to emit Java 21 bytecode.
- Paper/Purpur 1.21.11 compatibility remains covered by dedicated compile and two-boot runtime gates.
- Paper 26.2 remains a supported backwards-compatibility/runtime-smoke line.
- The maintained addon bundle requires Paper 26.3 compile validation and continues to declare Minecraft 1.21.11 as its minimum compatibility generation.
- Existing item IDs, research IDs, storage keys, database schemas, saved-world formats, and normal gameplay semantics are unchanged.

## JEG / Enhanced Guide recipe stability — issue #281

- Fixed repeated recipe browsing failing when an addon recipe exposes Slimefun's immutable `ItemStackWrapper`.
- The shared machine-recipe index now converts immutable wrapper stacks into ordinary mutable recipe-display copies instead of calling the wrapper's intentionally unsupported `clone()`.
- This prevents the reported Infinity Workbench recipe view from falling back into the wrong generic/chest-style display after reopening a recipe.
- Added a regression test for the exact immutable-wrapper recipe path.
- No InfinityExpansion2 recipe IDs, layouts, or saved data are modified by this fix.

## Release baseline

- Previous stable regression baseline: exact released Slimefun Legacy 4.1.61 source commit `24a1030f1d4c6c4a928b939150befb4c5adc5b2e`.
- 4.1.61 remains immutable as the published previous stable release.
