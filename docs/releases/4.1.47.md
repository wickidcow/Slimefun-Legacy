# Slimefun Legacy 4.1.47

## Backpack name color support

- Added explicit color-code parsing when a new Slimefun backpack name is accepted from chat.
- Supports the classic Minecraft ampersand codes `&0`-`&f`, formatting codes `&k`-`&o`, and reset `&r`.
- Added `&#RRGGBB` hex-color shorthand, for example `&#FF8800Orange Backpack`.
- Plain backpack names remain unchanged.
- Invalid hex sequences remain literal instead of throwing an error.
- Backpack UUID, owner identity, inventory contents, storage keys and item IDs are unchanged; the change is cosmetic name formatting only.

## Regression coverage

- Added tests for plain names, legacy colors, formatting/reset codes, hex colors and invalid hex input.

## Compatibility

- Paper 26.2 remains the primary supported platform.
- Purpur 26.2 remains supported.
- Folia 26.2 remains experimental.
- Built with Java 25 and verified to the existing Java 21 bytecode target.
