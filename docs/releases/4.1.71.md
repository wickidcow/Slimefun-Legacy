# Slimefun Legacy 4.1.71 — Projector and Guide Maintenance

## Coordinated package

This maintenance package combines the Hologram Display Projector input-slot improvement with the **45 maintained addons in canonical bundle revision 126**, including **JustEnoughGuide 2.1.72**. It has its own release identity rather than replacing the existing 4.1.70 core or addon ZIP.

The release tag and the embedded core/bundle manifests identify the exact release source. Files are available only after the gated publication workflow completes; a source branch or Actions candidate is not itself a published release.

## Changes

The core includes the already merged Hologram Display Projector menu improvement that makes the item-input position clearer. Existing projector data, configured text/item behavior and other machine identities remain preserved.

JustEnoughGuide 2.1.72 fixes the offline-profile listener that attempted to access a live Player merely to log a name. Offline profile loads now run the normal guide-history patch and log the profile UUID. Repeated callbacks retain the existing patched history rather than resetting its page and queue. Normal player-join behavior and guide controls are unchanged.

All 44 other addon source pins remain unchanged from revision 125. The authoritative list of filenames, versions, commits and per-JAR checksums is `SF_ADDON_MANIFEST.json` inside the addon ZIP. FinalTECH remains 3.0.15; no additional addon feature/version cycle is introduced by this packaging release.

## Upgrade and compatibility

Stop the server and take a complete backup of worlds, databases, configuration and addon data before changing JARs. Test on a disposable copy first. Replace only the intended plugin files, remove older duplicates and retain existing configuration/data folders. Do not use plugin reload or destructive Doctor confirmation/quarantine commands as routine installation steps.

The Minecraft floor remains **1.21.11**, with 26.2 compatibility and 26.3 as the primary API target. Plugin bytecode targets Java 21; use the Java version required by the chosen server generation. The recorded 26.3 server and WorldEdit provider were beta builds. Paper/Purpur are primary platforms; Folia is experimental and every installed addon needs its own region-safety support.

WorldEditSlimefun requires a compatible external WorldEdit/FAWE provider, which is not included in the addon ZIP. SF_BetterStructuresLink remains separately scoped and is not part of these 45 addons. Deliberately excluded or integrated historical addons are not reintroduced.

No supplied historical-owner-database test or copied production-world playthrough has been completed. Builds, archive audits and focused runtime checks do not certify every player menu, machine/Cargo interaction, old-world upgrade or cross-fork rollback. No live-server data was changed in preparing this package.
