# Slimefun Legacy 4.1.72 — Doctor Recovery & Purpur 26.3 Validation

**Release candidate. Not published until all exact-source gates complete.**

## Overview

Slimefun Legacy 4.1.72 brings together the new **read-only historical item recovery preview**, experimental **Purpur 26.3** runtime testing of the canonical maintained addon stack, and **45 maintained addon JARs from bundle revision 129**. This package preserves published v4.1.71 and its revision-127 ZIP; no old release tag, JAR, or pack is replaced.

The support floor remains **Minecraft 1.21.11**, and the universal core/addon bytecode target remains **Java 21**. Java 25 is used for modern 26.2/26.3 server test runtimes and the build toolchain. Paper 26.3 is the primary API target, and the existing Paper/Purpur 1.21.11 and 26.2 compatibility checks remain in place.

## 🩺 Slimefun Doctor — Legacy item recovery

The historical ID catalog now identifies the original addon for **all nine EnderPanda IDs** and the **four registered LuckyBlocks block IDs**. The sources and IDs are recorded as identification evidence only; they do not become automatic item replacements or migrations.

After a read-only scan, run:

```text
/sf doctor scan
/sf doctor migrations recovery
/sf doctor migrations recovery 2
```

The paginated recovery preview groups encountered IDs under their verified source addons (including EnderPanda, LuckyBlocks and InfinityExpansion) or **Unknown addon**. It shows registration/readiness and practical next steps. Counts for declared migration candidates are exact **only after a completed scan**; additional unknown IDs are bounded, distinct-ID samples and have **no invented per-ID item counts**. Already-restored, registered IDs from stale samples are not reported as missing.

The preview does not edit inventories, rename gear, force-load chunks, rewrite saved machine IDs, alter resource-pack metadata, or run addon migration providers. Lucky Armor and weapons are enchanted vanilla drops rather than Slimefun IDs; their opt-in English-name repair remains in **SF_LuckyBlocks v1.0.4** as `/luckyrestore check` and `/luckyrestore hand`.

The `SHULKER_HELMET` restoration remains part of the preceding 4.1.71 release. The other eight EnderPanda IDs are *identified* but not claimed to be fully restored.

## 🟣 Purpur 26.3 — experimental full-addon milestone

The core-only Purpur 26.3 smoke and the **full canonical maintained-addon ZIP** test succeeded against official experimental **Purpur 26.3 build 2646** in the dedicated pre-release CI. The full-stack test:

- Fetched the same-source core and exact canonical addon ZIP and checked addon-manifest provenance.
- Installed the required external WorldEdit provider alongside SF WorldEdit.
- Booted the test server twice and verified required addon registration, Java linkage/configuration loading and clean-shutdown persistence.
- Reported **45 of 45 maintained addons required and enabled**, zero dependency-gated addons, and no linkage/enable/configuration-load failures in the tested disposable environment.
- Preserved the existing Paper 1.21.11, 26.2 and 26.3 full-stack lanes.

CI evidence: [core Purpur milestone PR #360](https://github.com/wickidcow/Slimefun-Legacy/pull/360) and [45-addon Purpur milestone PR #361](https://github.com/wickidcow/Slimefun-Legacy/pull/361), including the [actual full-stack Purpur job](https://github.com/wickidcow/Slimefun-Legacy/actions/runs/37874115827).

**Purpur 26.3 remains experimental.** Passing the Slimefun bundle test does **not** certify ItemsAdder, MythicMobs, DeluxeMenus, BetonQuest, other AlbionMC-specific plugins, or an existing production world. A world upgraded to 26.3 may not be safely downgraded. **Folia 26.3 is not certified by this milestone.**

## Release safety and required verification

The previous **published stable baseline is v4.1.71**, tag source `f68544e47d8489704d0e9d34adc65f0114b07153`. Required addon compatibility regressions against this exact source block the candidate. The historical 4.1.15 compatibility floor remains advisory.

Publishing requires **fresh 4.1.72 final-source** Java/API, Doctor, database, addon, runtime and migration regression checks; the exact 45-JAR revision-129 bundle; full-stack verification; two byte-identical clean core builds; release-artifact validation; and byte-level verification of the pinned optional resource pack. The preceding PR and 4.1.71 results are source-attributed evidence, not substitutes for the final 4.1.72 release build.

Only the repository's existing gated **Reproducible Release** workflow may publish this version. Do not relabel an Actions artifact or upload a previous-source ZIP under the 4.1.72 tag.

For server installation: stop the server, back up all worlds, databases, player inventories, and plugin/addon folders, test with a cloned world and matching plugin set, and remove superseded duplicate JARs. Keep existing data and configuration. Do not use hot-reload, unknown-ID deletion, or automatic migration as a normal update procedure.

Slimefun Legacy startup/full-stack CI does not prove gameplay correctness for every connected player, world conversion, machine transfer or unsupported addon. **AlbionMC production-world migration has not been performed or certified as part of this release preparation.**
