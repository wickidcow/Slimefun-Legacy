# Slimefun Legacy 4.1.41 Development Plan

## Theme
Maintenance & Compatibility

## Release principles

- Keep 4.1.40 as the stable production baseline while 4.1.41 is developed on its own branch.
- Prefer measured, profiler-driven performance work over broad rewrites.
- Preserve existing item IDs, saved-world data, machine behavior, and addon-facing compatibility.
- Avoid migrations and disruptive gameplay changes in the 4.1.x line.

## Initial work

- Leaf 26.2 Paper-family runtime smoke coverage.
- Correct negative-Y hotspot coordinates in `/sf tick top`.
- Reduce Electric Smeltery idle recipe-check overhead.
- Profile and optimize remaining high-cost core ticker paths only when supported by measurements.
- Expand regression coverage around any optimized machine before release.

## Release gate

4.1.41 should remain unreleased until Paper 26.2 compatibility and runtime smoke tests pass and the development changes have been validated on a production-like server.
