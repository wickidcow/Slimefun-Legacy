# Slimefun Legacy 4.1.54

Slimefun Legacy 4.1.54 completes the move back to a standalone enhanced guide while preserving the hardened Legacy services that made the integrated guide safer.

## Standalone SF_JustEnoughGuide

- The preferred enhanced guide is now the standalone **SF_JustEnoughGuide** addon.
- The former native Enhanced Guide remains available only as an opt-in compatibility fallback.
- When `JustEnoughGuide` is installed, Slimefun Legacy leaves the classic guide registered so the addon can replace it cleanly.
- Existing `plugins/Slimefun/enhanced-guide.yml` settings and `guide-bookmarks.yml` data can be imported by the maintained JEG fork.
- `SF_JustEnoughGuide2.1.55.jar` is included in the canonical Slimefun Legacy addon bundle.

## Safe guide registration API

Slimefun Legacy now exposes supported guide registration methods so guide addons no longer need to overwrite the private guide registry through reflection:

- `registerSlimefunGuide(...)`
- `compareAndSetSlimefunGuide(...)`

The compare-and-set restore path prevents an addon from overwriting another guide implementation that replaced it later.

## Machine recipe and input-fill services

The Legacy machine recipe provider registry and hardened machine input-fill service now initialize independently from the former native Enhanced Guide UI.

This keeps the following protections available to standalone guide addons:

- protection and target validation;
- region-thread ownership checks;
- transactional inventory planning;
- rollback on failed commits;
- registered addon machine adapters;
- alternative ingredient validation;
- maximum safe fill support.

## Doctor integration

The maintained SF_JustEnoughGuide addon can expose Slimefun Legacy Doctor shortcuts for status, core, compatibility, dependencies, runtime, integrations, upgrade readiness, and read-only item scans. Repair and migration actions continue to use Slimefun Legacy's normal confirmation and fingerprint safeguards.

## Compatibility

The maintained compatibility range remains:

- Minecraft 1.21.11
- Minecraft 26.1.x
- Minecraft 26.2
- Minecraft 26.3

Paper and Purpur remain the primary targets, with Folia and Leaf as secondary compatibility targets.
