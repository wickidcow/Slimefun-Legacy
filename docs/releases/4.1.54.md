# Slimefun Legacy 4.1.54 — Standalone JustEnoughGuide Handoff

Slimefun Legacy 4.1.54 restores JustEnoughGuide as a maintained standalone addon while keeping the hardened guide APIs, machine recipe providers, protection checks, transaction planning, rollback logic, and Doctor tooling in Slimefun Legacy core.

The matching maintained addon release is **SF_JustEnoughGuide 2.1.55**.

## Standalone JustEnoughGuide

The native Enhanced Guide is no longer the default Slimefun Legacy UI.

For new installations:

- the native Enhanced Guide defaults to disabled
- the classic indexed Slimefun guide remains the core fallback
- when `JustEnoughGuide` is installed, Slimefun Legacy leaves the core guide registered during startup and lets the addon install its guide through the supported registration API
- the former native Enhanced Guide remains available as an opt-in fallback when JEG is not installed

Existing servers with `enhanced-guide.yml` set to `enabled: true` do not need to disable it manually before installing the maintained JEG addon. The standalone addon takes precedence when detected.

## Safe guide registration API

Slimefun Legacy now exposes supported guide replacement and restoration APIs instead of requiring addons to modify the private guide registry:

- `registerSlimefunGuide(...)`
- `compareAndSetSlimefunGuide(...)`

The compare-and-set restoration path prevents a disabling addon from overwriting another addon that replaced the guide after it.

## Core services remain in Slimefun Legacy

Moving the UI back into an addon does **not** remove the safety work added to Slimefun Legacy.

The core continues to own and initialize:

- machine recipe provider registration
- hardened machine input-fill adapters
- protection and ownership checks
- scheduler/region ownership checks
- transaction simulation
- inventory commit validation
- rollback after failed transfers

These services remain available even when the native Enhanced Guide UI is disabled.

## SF_JustEnoughGuide 2.1.55

The maintained standalone addon adds the Legacy-facing UI back on top of those core services.

Highlights include:

- English-facing player and administrator text
- Slimefun Legacy Doctor menu shortcuts
- Legacy machine recipe browsing
- safe machine-input filling delegated to Slimefun Legacy core
- migration of compatible `plugins/Slimefun/enhanced-guide.yml` settings
- migration of existing `plugins/Slimefun/guide-bookmarks.yml` bookmarks
- supported guide install/restore through the new Legacy registration API
- compatibility fallback for older/upstream Slimefun implementations
- canonical artifact name `SF_JustEnoughGuide2.1.55.jar`

### GuizhanLib no longer required

SF_JustEnoughGuide 2.1.55 removes the GuizhanLibPlugin dependency and its updater integration.

The small ItemStack display-name helper previously obtained through GuizhanLib is implemented locally in the maintained addon, so JEG no longer refuses to start when GuizhanLibPlugin is absent.
