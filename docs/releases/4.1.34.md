# Slimefun Legacy 4.1.34

## `/sf give` compatibility fix

- Fixed `/sf give <player> <item>` failing with `NoClassDefFoundError` when the relocated Dough `PlayerList` helper is unavailable at runtime.
- Slimefun now uses Bukkit's exact online-player lookup for the give command instead of the obsolete Dough helper.
- This restores `/sf give` for core Slimefun items and addon items, including Magic Expansion fishing rods.

## Optional external resource-pack support

Slimefun Legacy can now send an externally hosted resource pack to players without requiring AdvanceTexture or another resource-pack sender plugin.

- Resource-pack delivery is **disabled by default**.
- Existing ItemsAdder, Oraxen, proxy, or custom resource-pack setups are untouched while the feature remains disabled.
- Server owners can enable the sender in `plugins/Slimefun/config.yml` and choose any direct HTTP(S) resource-pack ZIP URL.
- The pre-filled URL matches AdvanceTexture's public `official_pack_1211` option:
  `https://cdn.modrinth.com/data/TznkVJky/versions/nwij66MR/Slimefun-ResourcePack.zip`
- Optional SHA-1, required-pack behavior, and prompt text are configurable.
- The sender uses the additive Minecraft/Paper resource-pack API so an explicitly enabled Slimefun pack can coexist with another server pack instead of replacing it.
- The sender implementation targets the modern Minecraft 1.21.11+ / current Paper API line.

The pre-filled third-party Modrinth pack is maintained separately from Slimefun Legacy. Server owners can replace the URL with their own current pack at any time.

## Paxel resource-pack compatibility

- Added the established FluffyMachines Paxel model mapping to Slimefun Legacy defaults.
- `PAXEL` and `ADVENTURERS_PAXEL` intentionally share CustomModelData `2201302`.
- Their Slimefun item IDs remain separate, preventing registration conflicts when FluffyMachines and Adventurer's Curios are both available.
- Final configured model mappings are now reapplied after Slimefun/addon item registration so canonical Guide items receive the same model data as normal created items.
- This fixes the timing gap where a Paxel could have the correct model in a player's inventory while the Slimefun Guide template still rendered as the vanilla tool.

## Compatibility and packaging

- No AdvanceTexture dependency or code is bundled.
- No resource-pack ZIP is bundled into the Slimefun Legacy JAR.
- No automatic external pack download or upload service is started.
- Java 25 remains the supported runtime/toolchain and Slimefun-owned classes continue targeting Java 21 bytecode.
- Paper 26.2 remains the primary validated server line, with the optional resource-pack sender written against the modern 1.21.11+ compatible API surface.
