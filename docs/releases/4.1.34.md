# Slimefun Legacy 4.1.34

Slimefun Legacy 4.1.34 is a focused compatibility and quality-of-life release for modern Paper servers. It restores a broken core admin command, adds an optional native resource-pack delivery path, and tightens Paxel model integration while keeping compatibility and server-owner control at the center.

## Highlights

### `/sf give` works again

The `/sf give <player> <item>` command could crash on current builds with a `NoClassDefFoundError` for Dough's relocated `PlayerList` helper. 4.1.34 removes that fragile dependency from the command and uses Bukkit's exact online-player lookup instead.

That means `/sf give` is restored for both core Slimefun items and addon items — including Magic Expansion fishing rods and other registered addon content.

### Optional native external resource-pack delivery

Slimefun Legacy can now send an externally hosted resource pack directly to players without requiring AdvanceTexture or another dedicated pack-sender plugin.

- **Disabled by default** — existing ItemsAdder, Oraxen, proxy, or custom pack setups remain untouched unless you opt in.
- Supports any direct HTTP(S) resource-pack ZIP URL.
- Optional SHA-1 verification, required-pack behavior, and custom prompt text are configurable.
- Uses the modern additive Minecraft/Paper resource-pack API so an enabled Slimefun pack can coexist with another server pack instead of replacing it.
- Includes the same public `official_pack_1211` URL currently used by AdvanceTexture as the pre-filled example/default.

No AdvanceTexture code is bundled, no resource-pack ZIP is embedded in the plugin, and Slimefun Legacy does not start a local pack-hosting service.

### Better Paxel texture integration

Paxel model handling has been tightened so the Guide and normal created items stay visually consistent.

- `PAXEL` and `ADVENTURERS_PAXEL` share the established CustomModelData value `2201302`.
- Their Slimefun IDs remain separate, avoiding registration conflicts between FluffyMachines and Adventurer's Curios.
- Final model mappings are reapplied after Slimefun and addon registration so Guide templates receive the same configured model data as regular items.
- Fixes cases where a Paxel looked correct in a player's inventory but appeared as a vanilla tool in the Slimefun Guide.

## Compatibility

This release remains centered on the current Slimefun Legacy target stack:

- **Paper 26.2** primary validated server line
- **Java 25** supported runtime/toolchain
- Slimefun-owned classes continue targeting **Java 21 bytecode**
- Modern **Minecraft 1.21.11+ / Paper API** resource-pack support

The final 4.1.34 candidate passed the full release validation set, including Build English Slimefun, Runtime Gameplay Correctness, the Paper 26.2 two-boot runtime smoke, Public API Compatibility, and the Slimefun compatibility matrix. Required addon checks for FastMachines Legacy, Networks Expansion Legacy, SlimeTinker IE2 Legacy, and BetterChests Legacy also passed, along with the Magic Expansion advisory compatibility check.

## For server owners

4.1.34 is intended as a drop-in upgrade from 4.1.33. The new resource-pack sender stays off unless explicitly enabled, while the `/sf give` compatibility fix applies automatically.

Thanks for continuing to test Slimefun Legacy on current Minecraft versions and helping keep the classic Slimefun experience alive on modern servers.
