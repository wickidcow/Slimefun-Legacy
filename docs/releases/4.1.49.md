# Slimefun Legacy 4.1.49

Slimefun Legacy 4.1.49 is a post-4.1.48 maintenance release focused on Enhanced Guide polish, clearer server-owner controls, maintained-addon recognition, and preparation for Paper 26.3 while keeping Paper 26.2 as the production baseline.

## Enhanced Guide and Settings & Info

- Added a **What's New?** entry with the installed Slimefun Legacy version and a direct link to the latest release notes.
- Added permission-gated server-owner shortcuts in **Settings & Info** for `/sf versions`, `/sf update check`, and `/sf stability status`.
- Preserved the Survival/Cheat guide-mode toggle for players with `slimefun.cheat.items`.
- Kept Enhanced Guide cheat behavior consistent: right-click gives a full stack and Shift-click manages bookmarks.

## Guide performance

- Kept Enhanced Guide bookmarks cached per player and evicted the cache on quit.
- Protected bookmark caching and click semantics with regression checks.
- Sorted and froze reverse recipe-usage lists once when the index is published, so reopening **Recipes Using This Item** reuses cached ordered results instead of copying and sorting them again.

## Addon compatibility

- Improved recognition of maintained `wickidcow/SF_*` addon forks whose runtime plugin names differ from their repository names.
- Corrected Military Arsenal's `WeaponsAddon` runtime-name mapping.
- Added a centralized advisory Maven/Gradle compiler for maintained addons against the Paper 26.3 candidate stack.
- The Paper 26.3 lane remains advisory; Paper 26.2 remains the production/runtime baseline.
- Before this release, the required compile tier was revalidated successfully for BetterChests, FastMachines, NetworksExp, and SlimeTinkerIE2.

## Platform and build

- Primary production target: Paper 26.2.
- Purpur based on Paper 26.2 remains supported.
- Folia remains experimental and requires Folia-safe addons.
- Built with Java 25 while retaining Java 21 bytecode for Slimefun-owned classes.

## Release assets

- `Slimefun-Legacy4.1.49.jar`
- `SFL_AddonsNDependencies.zip`
- `SFL_AddonsNDependencies.sha256` after the post-publication bundle verification pass.

The addon bundle is refreshed from the latest maintained addon releases and validated separately after publication so the release page carries the current Slimefun Legacy addon/dependency set.
