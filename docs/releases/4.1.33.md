# Slimefun Legacy 4.1.33

Slimefun Legacy 4.1.33 expands Adventurer's Curios with new field tools, excavation equipment and radioactive combat gear, while adding a server-owner update notice and keeping the release validated against the supported compatibility baseline.

## Adventurer's Curios

- Expanded the Curios collection with additional expedition and field-engineering items, including the Bastion Resonator, Chunk Stabilizer, Echo Locator, Emergency Flare, Field Repair Kit, Geiger Counter, Rescue Whistle, Salvager's Magnet, Surveyor's Rod and Wayfarer's Lodestone.
- Organized the Curios guide into clearer Curiosities, Tools, Armor and Irradiated Arsenal sections while preserving existing item-group compatibility where required.
- Added a built-in **Paxel** (`ADVENTURERS_PAXEL`) that combines pickaxe, axe and shovel behavior and automatically adapts its vanilla tool form to the block being mined.
- The Curios Paxel begins as Diamond equipment and can be upgraded to Netherite through the Smithing Table.

## Deepcore Tunnel Tools

- Replaced the single selectable tunnel-borer mode with nine fixed tools:
  - Deepcore Tunnel Pickaxe: **3x3, 5x5 and 9x9**
  - Deepcore Tunnel Shovel: **3x3, 5x5 and 9x9**
  - Deepcore Tunnel Paxel: **3x3, 5x5 and 9x9**
- Each tool excavates up to **3 blocks forward** while keeping the tunnel floor anchored at the player's feet and growing upward.
- Pickaxes expand through pickaxe-mineable terrain, shovels through shovel-mineable terrain, and paxels support both terrain sets.
- Sneaking keeps precision single-block mining available.
- Deepcore excavation continues to respect Slimefun protection checks, world borders, unloaded chunks, machines, storage, custom blocks and tile entities.
- Larger tiers use progressively longer short cooldowns and progressive durability wear to reduce accidental server-load spikes.
- The **3x3 Deepcore Tunnel Paxel now requires a Netherite-upgraded Paxel** as its core ingredient.
- That recipe accepts either the built-in `ADVENTURERS_PAXEL` or, when FluffyMachines is installed, its existing `PAXEL` item without creating a hard addon dependency.
- Netherite Paxels are accepted in their pickaxe, axe or shovel adaptive state, so crafting does not depend on which block the Paxel mined last.
- The 5x5 and 9x9 Deepcore Paxels continue the upgrade chain from the previous Deepcore Paxel tier.

## Irradiated Arsenal

Added a new radioactive combat branch under Adventurer's Curios using blistering-alloy recipes:

- Glowbite Blade
- Geiger Pike
- Hot-Zone Cleaver
- Reactor's Fork
- Critical Mass
- Radspike Arrows

These weapons apply radiation exposure to targets and can leak a smaller amount of radiation while held, tying the arsenal into Slimefun Legacy's existing radiation systems and protective equipment.

## Update notifications

- Added GitHub release checking for newer Slimefun Legacy versions.
- Server console and online operators receive a clear update notice showing the installed version, latest version and the `/releases/latest` download link.
- Repeated checks do not spam the same release tag during one server session.

## Release and compatibility work

- Updated 4.1.33 release/compatibility metadata and validation baselines.
- Preserved the Java 21 bytecode target while building the project with the current release toolchain.
- Validated the candidate through the normal Slimefun Legacy build, gameplay correctness, Paper 26.2 two-boot runtime smoke and public API compatibility checks.
- Continued cross-fork and representative-addon compatibility checks for Legacy, United, Gugu and supported addon integrations.
