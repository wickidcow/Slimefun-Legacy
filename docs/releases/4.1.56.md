# Slimefun Legacy 4.1.56

Slimefun Legacy 4.1.56 makes recovery and resource-pack administration much clearer from the Slimefun Guide while fixing the remaining real-time guide-search dependency problem.

## Slimefun Doctor in the Guide

Operators with `slimefun.command.doctor` now get a dedicated **Slimefun Doctor** button in Guide settings.

The resource-pack section deliberately separates four different operations so enabling a pack is never confused with rewriting item data:

- **Enable Resource Pack** — turns Slimefun Legacy's own pack delivery on. It does not change `item-models.yml` or stored items.
- **Upgrade Items for Resource Pack** — adopts exact bundled Legacy model IDs only where the current mapping is `0`, then updates eligible reachable Slimefun items.
- **Disable Resource Pack** — turns only Slimefun Legacy's pack delivery off and removes Legacy's pack UUID from online players. It does not strip item models.
- **Remove Resource-Pack Item Models** — resets exact bundled Legacy mappings and guides the operator through the restart and stored-item cleanup path.

Server-wide item mutation actions retain explicit confirmation and backup guidance.

## Other Doctor Fixes

The new **Other Doctor Fixes** submenu gives administrators recovery paths when the problem is not specifically the resource pack:

- **Full Doctor Scan** — read-only server-wide diagnosis and next-step classification.
- **Repair Names & Lore** — confirmed repair of safely recoverable presentation data.
- **Scan Item Models** — read-only stale bundled-model inspection.
- **Legacy-ID Migration Plan** — correlates the latest Doctor scan with addon migration providers and registered legacy IDs.
- **Runtime & Storage Health** — shows pending database writes, machine isolation state, shutdown evidence, and Doctor progress.

## Resource-pack sender controls

Slimefun Legacy can now persist the server-level resource-pack sender toggle directly through `configSFLAddons.yml`.

Enabling or disabling the sender is intentionally separate from item-model conversion. The sender controls only Slimefun Legacy's own pack UUID and does not remove or replace packs owned by ItemsAdder, Oraxen, a proxy, or another plugin.

Player-level opt-in, opt-out, and reload controls remain available separately from the admin Doctor tools.

## Generalized item-model cleanup

`/sf doctor item-models remove-resourcepack-texture-ids` is no longer limited to servers carrying the historical v4.1.52 migration marker.

The cleanup now handles any mapping that still exactly matches Slimefun Legacy's bundled resource-pack model value, including mappings intentionally adopted later through Doctor. Custom or non-matching model values are preserved.

The historical aliases remain available for compatibility:

```text
/sf doctor item-models rollback-v52
/sf doctor item-models recover-v52
/sf doctor item-models v52-recovery
```

The clearer command is:

```text
/sf doctor item-models remove-resourcepack-texture-ids
/sf doctor item-models remove-resourcepack-texture-ids confirm
```

After mappings are reset, stop the server normally, restart, run `/sf doctor item-models scan`, and use `/sf doctor item-models repair confirm` only after reviewing the scan.

## Guide search repair

Classic, Enhanced, and Indexed Enhanced guide search now use Slimefun Legacy's native Paper chat catcher instead of Dough's `ChatInput` helper.

Pending guide-search input can also consume the player's search message when another plugin has already cancelled the chat event. This restores the real-time search path without adding a new Dough dependency to the Guide runtime.

## Compatibility and validation

The maintained compatibility range remains:

- Minecraft 1.21.11
- Minecraft 26.1.x
- Minecraft 26.2
- Minecraft 26.3

Paper 26.2 remains the production baseline. Paper 26.3 continues through dedicated pre-release and full-stack validation. Velocity modern forwarding remains the maintained proxy path.

4.1.56 uses the exact `v4.1.55` release commit as its release-blocking previous-stable compatibility baseline. The historical 4.1.15 floor remains advisory.

The canonical release continues to publish exactly two assets: the raw Slimefun Legacy JAR and the validated `SF_Addons_1.21.11-26.3.zip` bundle.
