# Slimefun Legacy 4.1.51

Thanks for sticking with the project. **Sorry for the delay getting these updates packaged together.** The last few days turned into a much larger compatibility, migration, and addon cleanup than expected, and I wanted the release to go out as one tested set instead of pushing a pile of half-finished JARs.

## What changed in Slimefun Legacy

4.1.51 is mainly a **stability, upgrade-safety, and compatibility release**.

- **Safer backpacks:** closes duplication/session race conditions, protects backpack identity while a backpack is opening or in use, and makes save/close handling more defensive.
- **Much stronger `/sf doctor` upgrades:** old Slimefun IDs can now be found and migrated safely in placed block records, universal records, machine inventories, and persisted backpacks without blindly loading chunks or rewriting unknown data.
- **Safer addon migrations:** maintained addons can hand Slimefun exact migration candidates with state checks, fingerprints, revalidation, and rollback instead of relying on broad ID replacement.
- **Purpur 1.21.11 storage fix:** empty/AIR ItemStacks are normalized before serialization so they no longer hit Paper/Purpur's `Empty itemstack cannot be serialized` error.
- **ExtraTools cleanup:** the built-in ExtraTools guide page is more reliable and one conflicting legacy item can no longer hide the entire module.
- **Minecraft/Paper 26.3 preparation:** Slimefun Legacy now recognizes 26.3, compiles against the current Paper 26.3 API, and has dedicated 26.3 gameplay/runtime checks for the Guide, machines, storage, Cargo, EnergyNet, recipes, and restart safety.
- **Less reliance on Paper internals:** removed the old Paper profile cast and the `MCUtil.MAIN_EXECUTOR` reflection path that could become a future compatibility problem.

## Updated addon bundle

This release includes **`SFL_Addon1.21.11-26.3.zip`**, built from the maintained addon repositories and verified as a single compatibility bundle.

The bundle keeps:

- **Minecraft 1.21.11** as the minimum/base compatibility target.
- **26.1.x and 26.2** supported.
- **26.2 as the current production baseline.**
- **26.3 as a compatible candidate** while Paper/Minecraft 26.3 is still moving toward a stable server release.
- **Paper and Purpur** as the primary server platforms.
- **Folia and Leaf** as secondary compatibility platforms.

### Notable addon work from the last few days

- **InfinityExpansion2 2.0.8** — Mob Simulation Chambers now support configurable random drop amounts such as `1-5`, reject invalid Cargo/player inputs before processing, and keep the newer migration safety work.
- **Networks 1.0.20** — current maintained transport/matching work is included, along with the newer blueprint compatibility/migration handling.
- **BetterChests 1.0.2** — safer legacy drawer recovery and IE Storage handling, with unsafe or ambiguous stored data failing closed instead of being silently destroyed or normalized.
- **DynaTech 1.1.03** — maintained legacy-machine migration support with exact state checking; unsafe schema changes such as the old Auto Kitchen remain deliberately protected rather than blindly converted.
- **FinalTECH 3.0.2** — the current maintained build includes the startup/YAML, Guide presentation/help, and modern Slimefun compatibility cleanup from the recent maintenance work.
- **MobCapturer 1.0.6** — current maintained build includes the modern compatibility work and the Paper 26.2 bStats startup-linkage fix.
- **DracFun 1.0.2** — modernized for current Slimefun Legacy/Paper-family servers with updated scheduling, storage safety, and migration handling.
- **SlimeHUD 2.0.1** — modernized HUD support with BossBar/ActionBar player choice and current Slimefun Legacy compatibility.
- **MagicExpansion 1.1.5, Cultivation 1.1.23, FluffyMachines 26.2.12, FNAmplifications 4.2.7, LiteXpansion 1.0.2, DankTech2 1.1.02, Supreme 1.0.12, Relics of Cthonia 2.0.3, Galactifun 1.0.7** and the rest of the maintained bundle have all been rebuilt through the same 1.21.11-26.3 compatibility bundle process.

The goal of the ZIP is simple: **one place to get the currently maintained Slimefun Legacy addon builds without hunting through dozens of repositories.**

## Before upgrading an old server

Back up the server first. After updating Slimefun Legacy and the maintained addons, use `/sf doctor upgrade` and the Doctor migration commands to review older saved data before running any explicit migration action.
