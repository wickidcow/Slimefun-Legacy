# Slimefun Legacy 4.1.51

Slimefun Legacy 4.1.51 packages the recent stability, migration-safety, and Minecraft/Paper 26.3 compatibility work into one release candidate tested against the maintained compatibility lanes.

## Core changes

- **Safer backpacks:** closes duplication/session race conditions, protects backpack identity while a backpack is opening or in use, and makes save/close handling more defensive.
- **Expanded `/sf doctor` migration coverage:** legacy Slimefun IDs can be found and migrated safely in placed block records, universal records, machine inventories, and persisted backpacks without blindly loading chunks or rewriting unknown data.
- **Safer addon migrations:** maintained addons can provide exact migration candidates with state checks, fingerprints, revalidation, and rollback rather than relying on broad ID replacement.
- **Purpur 1.21.11 storage fix:** empty/AIR ItemStacks are normalized before serialization so they do not hit Paper/Purpur's `Empty itemstack cannot be serialized` failure.
- **ExtraTools guide/registration hardening:** one conflicting legacy item can no longer hide the complete module.
- **Minecraft/Paper 26.3 compatibility:** Slimefun Legacy recognizes 26.3, compiles against the Paper 26.3 API lane, and retains dedicated Guide, machine, storage, Cargo, EnergyNet, recipe, lifecycle, and restart checks.
- **Reduced Paper-internal coupling:** removes the legacy Paper profile cast and the Paper `MCUtil.MAIN_EXECUTOR` reflection path while preserving scheduler behavior.

## Addon compatibility bundle

The maintained addon set is published separately as **`SF_Addons_1.21.11-26.3.zip`**. The ZIP contains addon JARs only; the Slimefun Legacy core JAR remains a separate artifact.

Compatibility policy for this release:

- Minecraft **1.21.11** remains the minimum/base compatibility target.
- **26.1.x** and **26.2** remain supported.
- **26.2 remains the production baseline.**
- **26.3 is the current compatibility candidate** and is exercised by the dedicated compile/runtime lanes.
- **Paper and Purpur** remain the primary server platforms.
- **Folia and Leaf** remain secondary compatibility platforms; Folia gameplay safety remains experimental where explicitly documented.

## Upgrade notes

Back up the server before replacing Slimefun Legacy or addon JARs. After updating, review `/sf doctor status`, `/sf doctor upgrade`, and the migration diagnostics before executing an explicit migration action. Do not use `/reload` for installation, upgrade, or repair.
