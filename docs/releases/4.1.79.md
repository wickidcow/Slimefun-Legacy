# Slimefun Legacy 4.1.79 — Preservation and Compatibility (unreleased candidate)

**Status: candidate only.** This file does not publish a release or establish that the exact combined build and addons are ready. Never overwrite or retag the published v4.1.78 release.

## Original gameplay and storage contracts

- Preserve original Slimefun gameplay, research gating, item/research IDs, persisted world/block/machine/storage data, recipes, production rates, energy, Cargo ownership, machine transaction and rollback behavior.
- The Advanced Farmer Android again delivers non-Ageable harvested outputs returned by add-on listeners such as ExoticGarden. If machine output fills, the remainder is preserved at the harvested block rather than lost. Existing mature Ageable-crop transaction and rollback flow remains unchanged. See [contributor PR #527](https://github.com/wickidcow/Slimefun-Legacy/pull/527) and [executable item-conservation tests #541](https://github.com/wickidcow/Slimefun-Legacy/pull/541).
- The compiler-only Paper 26.1.2 advisory lane now preserves its diagnostic artifact ([#495](https://github.com/wickidcow/Slimefun-Legacy/pull/495)). Do not infer safe runtime, old-world migration or rollback support from source compilation.
- Passive mob-drop gating improvements ([#555](https://github.com/wickidcow/Slimefun-Legacy/pull/555)) and honest 26.1.2 compatibility notices ([#557](https://github.com/wickidcow/Slimefun-Legacy/pull/557)) have merged into master. The combined 4.1.79 source still requires its own exact-head regression and full-stack validation before publication.

## Compatibility

- Minimum Minecraft **1.21.11**, with **Paper/Purpur 26.2** maintained and stable **26.3** the primary validation target.
- **26.1.2 is an advisory source-compilation lane only** until specific runtime and world-migration evidence is available.
- Java **21 bytecode**, tested with appropriate newer JDK toolchain.
- Folia/Leaf support must be separately evidenced for each addon and relevant runtime/region; do not infer parity from startup smoke tests.
- Only supported Java server-side APIs are developed here. No Bedrock/Geyser gameplay, protocol, data migration or asset editing is introduced.

## Installation and rollback

Back up worlds, Slimefun database, addon data and configurations first. Stop the server; replace the core JAR and the matched addon versions together; install the **player** resource pack for Java clients and optionally the unmodified **server-side** Geyser drop-in in the appropriate Geyser resource-pack directory. Restart the server normally; never rely on `/reload` for a complex plugin upgrade. Verify old player items and stored machine data before retiring backups.
