# Slimefun Legacy Wiki Source

This directory is the version-controlled source for the Slimefun Legacy documentation/wiki.

Start at **[Home](Home.md)**.

## Why keep the wiki in the repository?

- Documentation changes can be reviewed beside code changes.
- Version history is preserved with the project.
- Pages can be mirrored into the GitHub Wiki without losing a canonical source.
- Legacy-specific documentation stays separate from historical upstream Slimefun documentation.
