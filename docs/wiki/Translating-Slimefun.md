# Language and Translation

Slimefun Legacy is maintained as an **English-first** distribution. The normal English player experience does not require Slimefun Translate.

Recommended configuration for an English server:

```yaml
options:
  language: en
  enable-translations: false
```

Items created by older translated builds may retain stored display names or lore. For those cases, use the conservative repair workflow in [Doctor & Diagnostics](Doctor-and-Diagnostics.md) rather than rewriting item metadata manually.

Historical Slimefun translation documentation may still be useful when working with other Slimefun forks, but it is not the primary operating model for Slimefun Legacy.
