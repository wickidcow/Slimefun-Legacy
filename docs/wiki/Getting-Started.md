# 🧪 Getting Started

Slimefun can feel enormous on day one. You do **not** need to learn every category at once. The best first session is a short progression from the Guide to basic resource processing, then into power and automation.

> [!TIP]
> If your server has research enabled, keep some XP levels available. Research costs are controlled by the server.

If you want the big-picture explanation first, read **[Slimefun Legacy in a Nutshell](Slimefun-in-a-Nutshell.md)**.

## 1. Get the Slimefun Guide

Use:

```text
/sf guide
```

Right-click the Guide and browse the categories. You can also search with:

```text
/sf search <name>
```

See [Enhanced Guide](Enhanced-Guide.md) for Legacy-specific guide features.

## 2. Understand research

Some items may appear locked. If research is enabled, select the locked item in the Guide and follow the prompt to unlock it with XP.

A server can change research behavior or grant permissions that alter this flow, so do not assume every server progresses identically.

Read **[Research & Progression](Research-and-Progression.md)** for a full progression strategy.

## 3. Build the Enhanced Crafting Table

This is the classic gateway into Slimefun crafting. It is a multiblock machine rather than a normal crafting-table recipe.

The in-game Guide shows the exact multiblock layout and recipe. Learn how multiblocks are displayed early — many classic Slimefun machines use them.

Continue with **[Multiblocks & Basic Machines](Multiblocks-and-Basic-Machines.md)** once you understand the Guide layout.

## 4. Start resource processing

A common early-game route is:

**Gravel → sifted material → washed dusts → ingots/alloys**

The classic tools and machines involved include the Gold Pan, Ore Washer and Smeltery. Use the Guide for the exact recipe and placement on your server.

See **[Resources, Dusts & Alloys](Resources-Dusts-and-Alloys.md)** for the larger material-production picture.

## 5. Make your first useful components

Once you can produce common dusts, ingots and alloys, browse **Technical Components** and the machine categories. These components are the backbone of later machines.

## 6. Move into electricity

When you begin crafting electric machines, learn three ideas:

1. **Generation** — where energy comes from.
2. **Storage/network capacity** — how much energy the system can buffer or move.
3. **Consumption** — what each machine needs while running.

Start with **[Energy Networks](Energy-Networks.md)**, then use [Energy, Cargo & Automation](Energy-Cargo-and-Automation.md) as the broader overview.

## 7. Automate repetitive work

Cargo and addon machines can turn manual processing into factories. Start with one small, understandable production line before building a giant network.

When a factory fails, diagnose it in layers: **recipe → input → output space → energy → Cargo direction/filter → chunk/region ownership → addon compatibility**.

Read **[Cargo Networks](Cargo-Networks.md)** before building a large factory.

## 8. Explore the signature systems

Once your workshop and first power network are stable, branch out into the systems that make Slimefun feel like a modpack:

- [🤖 Programmable Androids](Programmable-Androids.md)
- [🛰️ GPS, GEO & Teleportation](GPS-GEO-and-Teleportation.md)
- [🎒 Backpacks & Storage](Backpacks-and-Storage.md)
- [☢️ Radiation & Reactors](Radiation-and-Reactors.md)

## 9. Explore addons

Addons can add entire technology trees, storage systems, magic, weapons, agriculture and end-game progression. On Legacy, check addon health with `/sf versions` and the Doctor tools before assuming an older addon is safe.

See **[Addon Ecosystem](Addon-Ecosystem.md)** and [Compatibility & Addons](Compatibility-and-Addons.md).

## ✅ First-session checklist

- [ ] Obtain and open the Slimefun Guide.
- [ ] Search for the Enhanced Crafting Table.
- [ ] Learn how the Guide displays multiblock recipes.
- [ ] Unlock your first useful research.
- [ ] Produce your first basic Slimefun resources.
- [ ] Build a Smeltery and create a useful alloy.
- [ ] Browse Technical Components.
- [ ] Read the Energy guide before placing a large electric setup.
- [ ] Build one small Cargo route before a full factory.
- [ ] Bookmark a few next-goal items in the Enhanced Guide.
