# Permissions

Slimefun Legacy keeps the established Slimefun permission model wherever practical while adding modern administration and diagnostic commands.

The maintained Legacy permission reference is combined with the command reference here:

➡️ **[Commands & Permissions](Commands-and-Permissions.md)**
