# ⚒️ Multiblocks & Basic Machines

Before Slimefun becomes electric, much of its progression starts with **multiblock machines**: small structures built from ordinary Minecraft blocks that act as crafting or processing stations.

These machines are one of the most recognizable parts of classic Slimefun gameplay.

## Why multiblocks matter

Multiblocks teach the basic production chains without requiring an energy network. They are usually inexpensive, easy to repair and remain useful even after a factory becomes heavily automated.

Common early and mid-game multiblocks include:

| Machine | Typical role |
| --- | --- |
| **Enhanced Crafting Table** | Crafts many Slimefun recipes |
| **Grind Stone** | Early material processing |
| **Armor Forge** | Crafts specialized armor |
| **Ore Crusher** | Processes ores and materials |
| **Ore Washer** | Washes sifted/processed resources |
| **Smeltery** | Produces ingots and alloys |
| **Compressor** | Compresses materials |
| **Pressure Chamber** | Pressure-based crafting |
| **Magic Workbench** | Crafts magical items |
| **Ancient Altar** | Ritual-style crafting |
| **Automated Panning Machine** | Processes panning resources |

The exact recipe, block layout and enabled machines can vary by version, configuration and addon.

## Building from the Guide

Do not rely on an old screenshot or an old YouTube video when constructing a multiblock.

Open the current Slimefun Guide, select the machine and use the displayed structure/recipe as the authoritative layout for your server.

When a multiblock does not activate, check:

- every block type
- block orientation where applicable
- the interaction block you are clicking
- whether the structure crosses a protection boundary
- whether the item or machine is disabled
- whether an addon replaced or extended the recipe

## From manual to electric

A major progression milestone is replacing manual processing with electric equivalents.

For example, a player may begin with manual crushing, washing and smelting before moving into powered machines that perform the same production steps automatically or more efficiently.

That progression naturally leads into **[Energy Networks](Energy-Networks.md)** and **[Cargo Networks](Cargo-Networks.md)**.

## Multiblocks and protection plugins

Slimefun respects supported protection integrations. A structure can look correct but still refuse to operate if the player is not allowed to interact with part of it.

For server administrators, test multiblocks inside the same protection system used by players rather than only testing as an operator.

## Good factory design

Even in an advanced factory, keep a small manual-workshop area containing the important basic multiblocks. It provides:

- a fallback if power is unavailable
- easy access to low-volume recipes
- a teaching area for new players
- simpler troubleshooting when an electric recipe chain fails
