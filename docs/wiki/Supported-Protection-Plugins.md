# Supported Protection Plugins

Protection behavior is especially important for machine inventories, Cargo, Androids and custom interactions.

Use the maintained Legacy documentation here:

➡️ **[Protection Plugins & Claims](Protection-Plugins-and-Claims.md)**

Slimefun Legacy aims to fail closed when a supported protection integration cannot safely determine whether an action is allowed. Always test claim behavior with non-operator players on a staging server when changing protection plugins or addon builds.
