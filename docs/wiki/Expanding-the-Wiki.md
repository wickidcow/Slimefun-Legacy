# Help Expand the Slimefun Legacy Wiki

The Legacy wiki is maintained from Markdown files under `docs/wiki` in the Slimefun Legacy repository and published automatically to the GitHub Wiki.

To improve or correct a page, see:

➡️ **[Contributing to the Wiki](Contributing-to-the-Wiki.md)**

## What to improve

Good contributions include:

- correcting behavior that changed on current Paper versions;
- documenting Legacy-specific compatibility or diagnostics;
- improving unclear item or machine instructions;
- replacing outdated inherited Slimefun4 reference material with verified Legacy behavior;
- adding troubleshooting steps that are reproducible and safe.

For recipes and server-specific availability, the in-game Slimefun Guide remains authoritative.
