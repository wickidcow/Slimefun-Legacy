## A better way to browse than memorizing categories

When you have a specific goal, do not try to remember which category every intermediate item lives in.

1. Search for the final item with `/sf search <item>` or the Enhanced Guide search.
2. Open its recipe.
3. Follow unfamiliar ingredients backward.
4. Bookmark components you make often.
5. Build reusable production lines for repeated materials.

For factory progression, the common path is:

**Resources → Components → Electric Machines → Energy → Cargo → Advanced systems/addons**

## Addon categories

Addons can introduce completely new categories. Large Legacy installations may contain many more pages than the classic core alone.

If you are lost:

1. Use `/sf search <item>`.
2. Bookmark a progression goal in the Enhanced Guide.
3. Work backward through its ingredients.
4. Identify which addon owns the item if it is not core Slimefun.
5. Check [Addon Ecosystem](Addon-Ecosystem.md) if an older addon behaves differently on Legacy.

See **[Enhanced Guide](Enhanced-Guide.md)**, **[Addon Ecosystem](Addon-Ecosystem.md)** and **[Glossary](Glossary.md)**.
