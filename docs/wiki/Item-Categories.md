# 🗂️ Item Categories

The classic Slimefun wiki became useful partly because it grouped hundreds of items into understandable categories. Slimefun Legacy keeps that idea, but the **in-game Guide remains the authoritative category list** for a particular server.

Common classic categories include:

| Category | What you will usually find |
| --- | --- |
| ⚔️ Weapons | Slimefun weapons and combat equipment |
| 🧰 Items | General-purpose custom items |
| 🍔 Food | Special foods and ingredients |
| 🏗️ Basic Machines | Early multiblocks and processing machines |
| ⛏️ Resources | Dusts, ingots, alloys and processed materials |
| 🔧 Tools | Utility and mining tools |
| 🛡️ Armor | Protective equipment |
| ✨ Magical Armor | Armor with magical or special effects |
| 🔮 Magical Items | Runes, altar-related items and magical progression |
| 🪄 Magical Gadgets | Specialized magical utility items |
| 🧿 Talismans | Passive or triggered utility effects |
| ⚙️ Technical Components | Machine parts used throughout progression |
| 📦 Miscellaneous | Useful items that do not fit a single progression tree |
| ⚡ Energy & Electricity | Generators, storage and powered machines |
| 🛰️ GPS | Location and teleportation technology |
| 🧪 Technical Gadgets | Advanced technical utility items |
| 🤖 Programmable Androids | Androids, scripts and automation |
| 🚚 Cargo Management | Item logistics and factory automation |
| 🎃 Seasonal | Event or seasonal content when enabled |

## Addon categories

Addons can introduce completely new categories. Large Legacy installations may contain many more pages than the classic core alone.

If you are lost:

1. Use `/sf search <item>`.
2. Bookmark a progression goal in the Enhanced Guide.
3. Work backward through its ingredients.
4. Identify which addon owns the item if it is not core Slimefun.

See [Enhanced Guide](Enhanced-Guide.md) and [Compatibility & Addons](Compatibility-and-Addons.md).
