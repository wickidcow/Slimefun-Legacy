# Non-original Slimefun additions

Slimefun Legacy includes fork-specific gameplay additions by default, while still allowing server owners to disable them with one master switch.

By default, `options.enable-non-original-slimefun-additions` is `true` in `config.yml`.

- `true`: enables Adventurer's Curios and is the master switch for future Slimefun Legacy-only gameplay additions.
- `false`: disables Adventurer's Curios and future Legacy-only gameplay additions so only the original/core Slimefun content set registers.

Changing this setting requires a server restart because Slimefun items and item groups are registered during startup.
