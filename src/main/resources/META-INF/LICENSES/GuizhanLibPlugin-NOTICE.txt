Slimefun Legacy GuizhanLib compatibility bridge

This distribution contains selected compatibility classes from GuizhanLibPlugin 2.5.0 / GuizhanLib 2.5.0.
Upstream projects:
- https://github.com/ybw0014/GuizhanLibPlugin
- https://github.com/ybw0014/GuizhanLib

Upstream authors and contributors retain their copyrights.
GuizhanLibPlugin and GuizhanLib are distributed under the GNU General Public License v3.0.
A copy of that license is included beside this notice as GuizhanLibPlugin-LICENSE.txt.

Slimefun Legacy does not emulate or redistribute the GuizhanLibPlugin main JavaPlugin class.
The selected classes are bundled only to provide the library API expected by compatible Slimefun addons when the external GuizhanLibPlugin is absent.
