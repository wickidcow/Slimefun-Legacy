Slimefun Legacy Native Enhanced Guide — Phase 2 drop-in instructions

Required base
- Slimefun Legacy with Native Enhanced Guide Phase 1 already applied.
- The current Folia Phase 2 scheduler service must remain present.

Install
1. Back up the repository.
2. Extract the incremental changed-files ZIP into the repository root.
3. Preserve all paths and replace matching files.
4. Commit the files and run the normal GitHub Actions build.
5. Install the resulting Slimefun Legacy JAR on a copied Paper test server.
6. Fully restart; do not use /reload or a plugin reloader.
7. Remove the separate JustEnoughGuide JAR while testing the native guide.

Existing server configuration
- Existing enhanced-guide.yml files are safe: all new recipe-fill settings have code defaults.
- To expose the new settings for editing, merge the recipe-fill section from src/main/resources/enhanced-guide.yml or regenerate the server file.

Rollback
- Set features.recipe-fill.enabled to false and fully restart to disable only recipe filling.
- Set enabled to false and fully restart to restore the classic guide.
