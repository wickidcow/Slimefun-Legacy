Slimefun Legacy Native Enhanced Guide — Phase 3 drop-in instructions

Required base
- Slimefun Legacy with Native Enhanced Guide Phases 1 and 2 already applied.
- Keep the current Folia Phase 2 scheduler service and Phase 2 recipe-fill files in place.

Install
1. Back up the repository.
2. Extract the Phase 3 incremental changed-files ZIP into the repository root.
3. Preserve all included folder paths and replace matching files.
4. Commit the files and run the normal GitHub Actions build.
5. Install the resulting Slimefun Legacy JAR on a copied Paper test server.
6. Remove the separate JustEnoughGuide JAR while testing the native guide.
7. Fully restart; do not use /reload or a plugin reloader.

Existing server configuration
- Existing enhanced-guide.yml files remain valid because the new settings have code defaults.
- Merge the new unordered-machines, ancient-altar and missing-report entries when you want them visible in the server file.

Selective rollback
- Set features.recipe-fill.unordered-machines to false to disable the five new unordered machines.
- Set features.recipe-fill.ancient-altar.enabled to false to disable altar preparation.
- Set features.recipe-fill.ancient-altar.prepare-catalyst-in-hand to false to populate only pedestals.
- Set features.recipe-fill.missing-report.show-sub-recipe-hints to false to hide sub-recipe hints.
- Set features.recipe-fill.enabled to false to disable all recipe preparation.
- Set enabled to false to restore the classic guide after a full restart.
